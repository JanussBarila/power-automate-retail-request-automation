# Power Automate Setup Notes

The `definition.sanitized.json` file is included for portfolio/code review only.

It intentionally replaces:
- organization-specific names;
- user email addresses;
- OneDrive drive IDs;
- Excel file IDs.

Therefore it is **not intended to be imported directly** into another tenant.

For a deployable version, recreate the connections in the target Power Automate environment and select the local Excel file/table.
